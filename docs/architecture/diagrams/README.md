
## Diagrama de herencia de usuarios, roles y actores

Este diagrama representa la estructura jerárquica de los usuarios del sistema, mostrando las relaciones de herencia entre las diferentes clases y sus funcionalidades.

Complementa los diagramas de casos de uso y permite comprender la organización de los usuarios dentro del Sistema de Control Escolar.
